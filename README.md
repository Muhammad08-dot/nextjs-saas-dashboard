## 🚀 Overview
This repository contains a high-fidelity prototype of a SaaS Analytics Dashboard. Originally designed for a Next.js 14 stack, this Streamlit version is used to rapidly iterate on data visualizations, KPI placements, and user table layouts before committing to full React implementation.

## ✨ Features
- **Live KPI Tracking:** Visualizes MRR, Active Users, Signups, and Churn Rate.
- **Interactive Charts:** Revenue growth curves and user retention charts.
- **User Management:** Mock data tables displaying recent signups, plan tiers, and statuses.
- **Geographic Insights:** Revenue breakdown by global regions.

## 🛠️ Tech Stack (Intended)
- **Framework:** Next.js 14 (App Router)
- **Styling:** TailwindCSS
- **Database ORM:** Prisma
- **Current Prototype:** [Streamlit](https://streamlit.io/)

## 📦 Installation & Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Muhammad08-dot/nextjs-saas-dashboard.git
   cd nextjs-saas-dashboard
   ```

2. **Install dependencies:**
   ```bash
   pip install streamlit pandas
   ```

3. **Run the prototype:**
   ```bash
   streamlit run streamlit_app.py
   ```
